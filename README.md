# Study Planner Web Application

## System Description
Study Planner is a web-based application designed to help students organize their
weekly study schedule and manage their academic tasks efficiently.
The system allows users to view their planner, manage tasks, and navigate easily
between different pages of the application.
The application runs entirely in the browser and provides a simple and user-friendly
interface.

## Technologies Used
- HTML5
- CSS
- JavaScript
- Git & GitHub
- GitHub Pages (for deployment)

## Features
- Multi-page website (Home, Planner, Tasks, About)
- Navigation between pages
- Task management interface
- Planner interface
- Responsive design
- Clean and accessible UI

## How to Use the System
- Open the website using the provided link.
- Use the navigation menu to move between pages.
- In the Planner page, you can organize your weekly study schedule.
- In the Tasks page, you can add and manage tasks.
- The Home page shows an overview of your study activity.
- The About page explains the purpose of the system.
